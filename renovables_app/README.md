# Renovables en Argentina

Dashboard interactivo: historia 2011–2026, mapa por provincia, estacionalidad, pronóstico a 12 y 24 meses y backtest.

Correr local: `pip install -r requirements.txt` y `streamlit run app.py`.
Publicar: subir esta carpeta a un Space de Hugging Face (SDK Streamlit) o a Streamlit Community Cloud.
